# PMBA Dashboard

Aplicação visual de ciclo de estudos para o concurso da PMBA.

## Funcionalidades
* Grade interativa de disciplinas com persistência de progresso
* Pomodoro HUD integrado
* Diário de notas para controle global de disciplinas
* Sistema de Repetição Espaçada (SRS) integrado
* Interface totalmente local (funciona via navegador)

## Como Usar
Basta abrir o arquivo `index.html` em qualquer navegador moderno.

## Notas Técnicas
Todos os dados (progresso do ciclo, notas e flashcards) são armazenados localmente no navegador (`localStorage` e `IndexedDB`).
